# Public Audit & Timeline: OmniPhi (omniphi.ai) / Algoriphi, Inc.

This repository serves as a unified, open-source investigation tracking the PR stunts, marketing tactics, corporate genealogy, and technical realities surrounding OmniPhi.

## ⚖️ Operational Verdict
OmniPhi exhibits systemic traits of an early-stage SaaS venture substituting synthetic sentiment and institutional-grade PR shields for robust, deterministic financial infrastructure.

## 📅 The Chronological Unraveling

### 🔹 Phase 1: The Paid PR Blitz & Scarcity Funnels
* **Paid Media Laundering:** OmniPhi bypassed independent journalistic vetting by utilizing paid wire services (such as Newsfile Corp). This allowed them to place self-written press releases directly onto automated financial feeds like Yahoo Finance and StreetInsider, mimicking organic editorial coverage.
* **The "Claude Code for Trading" Hook:** Early marketing anchored its value proposition by comparing its conversational agent ("Phi") to advanced software development models, promising error-free trading strategies built purely from natural language.
* **Artificial Scarcity Tactics:** Marketing campaigns on social media leveraged algorithm-baiting phrases (e.g., *"Comment 'BETA' for access"*). This artificially spiked organic platform engagement while slow-rolling user access into arbitrary "Cohorts" to generate psychological FOMO.

### 🔹 Phase 2: Technical Contradictions & The Liability Shift
* **The Thin Wrapper Reality:** Technical analysis indicates that OmniPhi does not operate proprietary financial intelligence, but rather functions as an API wrapper around commercial third-party Large Language Models (LLMs), leaving it highly vulnerable to non-deterministic logic failures and hallucinations.
* **The "Own Your Code" Liability Swap:** Overwhelming marketing pitches user empowerment ("the code belongs to you"), but the legal Terms of Service reveal a structural shield. By forcing users to legally own the generated code, OmniPhi shifts 100% of the financial and legal liability onto the retail trader if a hallucinated strategy triggers account liquidation.
* **Astroturfing Indicators:** Early feedback profiles across consumer aggregators like Trustpilot exhibited highly coordinated review velocities, heavily flagged by open-source trackers as synthetic sentiment manipulation designed to drown out critical technical criticism.

### 🔹 Phase 3: Corporate Background & Regulatory Dockets
* **The Virtual Shell:** Corporate tracking confirms Algoriphi, Inc. operates entirely out of a standard mail-drop box in San Francisco (2261 Market Street, STE 70451), lacking a true physical or institutional footprint.
* **Historical Governance Red Flags:** Background tracking connects corporate entities and individuals associated with Algoriphi to past high-volatility restructurings, explicitly crossing paths with past **Alberta Securities Commission (ASC)** regulatory dockets and the fallout of Levitee Labs.

## 🔍 Deep-Dive Investigation Modules

### Module 1: The Beeks Financial Cloud Partnership Stunt
In late October 2026, OmniPhi deployed an aggressive public relations campaign centering on a "strategic partnership" and "minority investment" from Beeks Financial Cloud Group plc (LSE: BKS). Tracing the digital distribution pipeline reveals zero independent reporting:

* **The Wire Core (Newsfile Corp):** The primary press release was injected into global financial portals via Newsfile Corp, a flat-fee commercial distribution network. Content hosted on portals like Yahoo Finance or StreetInsider was generated automatically via these paid feeds. It received zero editorial cross-examination or journalistic curation.
* **The Missing Metrics:** While marketing copy leaned on institutional-grade vocabulary ("Tier-1 banking," "Sovereign GPU compliance"), the actual corporate filing disclosed zero dollar amounts invested, zero specific equity percentages acquired, and zero named enterprise clients.
* **The Incentives:** Beeks (a cloud server hosting business) lent its listed enterprise name to anchor an AI marketing narrative for its own LSE shareholders, while OmniPhi used the deal as an institutional shield to validate a volatile retail software wrapper.

### Module 2: Technical Wrapper & API Exposure Code Realities
OmniPhi markets its AI assistant, "Phi," as an advanced, autonomous trading intelligence engine. Behavioral analysis strips away this marketing layer:

* **Hallucination Mirroring:** When fed highly volatile macroeconomic inputs, "Phi" generates standard LLM semantic errors and syntax formatting quirks identical to raw commercial models like GPT-4o or Claude 3.5 Sonnet. It lacks an internal, mathematical core trained on microsecond institutional order routing.
* **The Software Insulation Defense:** Under standard investment advisory rules (Investment Advisers Act of 1940), providing automated investment advice requires strict fiduciary licensing. By declaring that the code exported "belongs entirely to the user," OmniPhi avoids registration as a licensed financial advisor.
* **The Human-in-the-Loop Trap:** Because the user must click "Approve" before a strategy goes live via API keys, the user legally absorbs 100% of the financial blame if the AI model hallucinated the strategy's risk parameters.
